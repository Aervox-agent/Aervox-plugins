# PostgreSQL 数据库

`ap-tool-postgresql`，主分类 `tool`。版本 `1.0.0`。

这是用户自主安装的可选扩展。SQLite 保持默认；出厂市场展示此插件，首次启动不创建安装、配置或授权记录。安装插件本身不会立即连接 PostgreSQL 或迁移数据库。

## 安装与配置

通过宿主插件市场或预检后的 `.aervox-plugin` 安装。声明包不执行 TypeScript/Vue，也不携带数据库连接串或凭据。PostgreSQL 配置、检查和离线迁移由配对宿主提供；本目录当前只有可选安装声明，不声明尚未接线的 HTTP、工具或 Page 能力。

连接串及密码由宿主管理，不进入普通插件配置。业务主库切换须在全部写者停止后，由宿主迁移和启动配置流程完成；填写连接信息或安装声明不证明数据已经迁移。未提供对应实现的宿主不能仅保存一个设置就宣称 PostgreSQL 主库可用。

## 数据与隐私

数据库、备份、删除、撤权和恢复责任属于宿主。插件停用或卸载不自动切回 SQLite、不删除业务数据，也不删除正在使用的宿主数据库凭据。插件源代码缺席时，宿主仍须保留数据库状态与修复入口。

本机私密 Vault、附件及独立恢复账本保持各自边界；`local_only` 来源不能因主库配置变化而进入远端数据库。连接失败或提交结果未知须明确报告，不静默创建空 SQLite 库或重放事务。

## 开发与许可

在配对宿主根冻结安装后运行集合 `lint-plugins.mjs`、本目录声明测试及可重现打包检查。实际 PostgreSQL 连接、业务仓储、迁移、重开和正式发布须分别取得证据。源码许可见 [LICENSE](LICENSE)；集合规范见 [SPECIFICATION.md](../../../SPECIFICATION.md)。
