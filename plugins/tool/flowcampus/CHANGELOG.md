# Changelog

## 1.1.0

- 新增最长 367 天的周课程、隔周与跨日安排，以及绑定原课程日期的单次调课、到达和取消。
- 新增有界 CSV/ICS 预览与选择确认导入，按稳定来源去重并提示冲突；编辑草稿和导入预览绑定 revision 与生命周期代际。
- 兼容扩展校园 v1 文档和配置 Schema v1，新增字段可选，旧数据不自动改写；保留既有工具、端点与权限边界。
- 修复日期线两端的周列表漏课、同文件单次/系列来源冲突迟报及合法 ICS 文本双引号解析。
