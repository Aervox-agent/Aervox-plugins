# Anki 闪卡与题库格式

## 只读格式查询

用户询问可导入的题库格式时，可调用 `anki_list_providers`，参数为 `{}`。结果只包含真实解析器的名称、说明与扩展名，需要当前插件的 `learning.read` 授权。

该工具不依赖 Anki endpoint、模型或配置，不读取题库正文或凭据。只有宿主实际提供该精确工具时才调用；缺端口、缺包、停用、换版或撤权时说明当前不可用，不编造清单或重复调用绕过权限。

## 闪卡与导入边界

可根据用户提供的笔记生成正反面闪卡文本供审阅，按宿主已有题库导入入口接受的格式保存。`anki_import_deck` 目前只有 Manifest 声明，没有执行 handler，不能调用它或宣称已入库、已排期。

若用户单独配置和授权外部 Anki MCP，只使用运行时实际呈现的动态工具并依其调用结果反馈；安装本插件不自动连接 MCP，不代表 OAuth、增量同步或冲突处理完成。没有真实成功结果时，明确文本仍待用户保存或导入。
