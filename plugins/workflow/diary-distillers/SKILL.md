# 日记风格与复盘

## 只读风格查询

用户选择复盘风格时，可调用 `diary_list_styles`，参数为 `{}`。结果只包含宿主真实风格的 `id`、名称、说明与应用场景，需要当前插件的 `diary.read` 授权。

该工具不依赖模型或配置，不读取记忆、日记正文或模板提示词。仅在运行时实际提供该工具时调用；缺端口、缺包、停用、换版或撤权时说明不可用，不编造返回清单。

## 草稿与生成边界

可根据用户本次提供的事实，在对话中起草复盘供审阅，不编造未发生的事件。`diary_generate_styled` 目前只有 Manifest 声明，没有执行 handler，不能调用它或宣称已生成持久日记。

宿主已有日记生成入口接受 `styleId`；仅当该入口返回真实成功结果时才报告生成完成。风格列表查询、对话草稿和插件安装都不代表持久写入。配置默认值不会因安装而自动影响 Worker 的生成风格，模型与后台管线可用性须依实际宿主状态判断。
