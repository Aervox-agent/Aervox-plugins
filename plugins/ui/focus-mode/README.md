# 专注模式与学习闭环

`ap-ui-focus-mode`，主分类 `ui`。版本 `1.0.0`。

CAP-002 / CAP-007 / CAP-016: 专注模式全流程学习闭环——涵盖苏格拉底启发式教学分步引导、现场刷题与判定出题、以及核心概念术语下钻探索插件。

## 安装与配置

通过宿主插件市场或 `.aervox-plugin` 预检后安装声明资源；受信 TypeScript/Vue 实现随宿主编译，声明包不会执行源码。配置以本目录 `config.schema.json`（若存在）和宿主界面为准。旧 `focus-mode` 身份必须先停写并运行显式迁移工具，勿并行安装以猜测合并。

## 学习入口

受信界面支持 `workbench` 与 `companion`。工作台保留原有学习菜单；陪伴首页通过 `companion:cards` 打开今日复习、学习规划或错题练习，`companion:drawers` 复用同一宿主上下文中的学习面板。今日复习与任务中心读取本机已保存的到期汇总，打开知识正文后记录“记得/还需复习”的自评，再展示保存回执中的下一日期、间隔、调度版本和时区；重开可查询最近完成记录。来源状态表达现有知识记录的证据状态，不代表外部授权或自动建议已验收。“本次先不看”只隐藏本次界面项，排期仍保留。

打开入口只导航，关闭后重开保留本次挂载的练习草稿和错误状态；回执不确定时保留原自评或作答请求，刷新不会替换其正文、幂等键、用时和提示数。知识内容不可读或发生变化时停止提交并提示核对。跨崩溃的未知意图恢复仍须按宿主持久化合同另行验收。

## 数据与隐私

配置、凭据、权限、业务数据由宿主管理；安装声明不等于外部服务已连接。外部连接仅在用户配置和授权后由对应宿主能力执行，缺包不删除数据，恢复代码不恢复已撤销授权。具体能力和已验证范围见宿主合同及测试。
